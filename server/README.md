## 1) كلمة مرور التطبيقات من Google (مرة واحدة)
1. افتح myaccount.google.com بحساب `daraluloom258@gmail.com` ← الأمان.
2. فعّل **التحقق بخطوتين** (2-Step Verification).
3. ابحث عن **App passwords** وأنشئ واحدة باسم «Dar OTP»، وانسخ الـ16 حرفاً.

## 2) النشر على Render (مجاني)
1. render.com ← New ← **Blueprint** ← اختر المستودع `DAR-CLAUD-AI` (يقرأ `render.yaml`).
2. أدخل المتغيرين:
   - `GMAIL_APP_PASSWORD`: كلمة مرور التطبيقات (من الخطوة 1)
   - `ALLOWED_ORIGINS`: عنوان تطبيقك (مثلاً رابط AI Studio المنشور)
3. بعد النشر انسخ رابط الخدمة (مثل `https://dar-otp-server.onrender.com`).

## 3) ربط التطبيق
اضبط `VITE_API_BASE_URL` برابط الخدمة (في إعدادات المتغيرات في AI Studio، أو سر في GitHub لبناء AAB).
اختبار سريع: افتح `<الرابط>/health` فيظهر `{"ok":true}`.
